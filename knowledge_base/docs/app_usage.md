# Using PawPal+

## Setting up an owner and pets
Start in Section 1: save an owner profile with a name and today's available
time budget (in minutes). Then add each pet with name, species, breed, and
date of birth -- age is calculated automatically. Owners can have any number
of pets.

## Adding tasks
In Section 2, add tasks one at a time: pick the pet, task type (walk,
feeding, meds, grooming, enrichment, appointment), duration, priority
(Low/Medium/High), and whether it's required. Required tasks (e.g.
medication) are always included in the generated plan regardless of the
time budget. Set frequency to "daily" or "weekly" for recurring tasks so
completing one automatically schedules the next occurrence.

## Generating a schedule
Section 3's "Generate Schedule" button fits tasks into the owner's daily
time budget: required tasks are locked in first, then optional tasks fill
remaining time in priority order, and the final plan is sorted
chronologically. If two tasks overlap in time, a warning banner explains
the conflict and suggests a new time -- conflicting rows are highlighted
amber in the plan table.

## Marking tasks complete
Section 4 lists all pending tasks sorted by time. Marking a daily or weekly
task complete automatically creates its next occurrence (+1 day or +7
days). After completing a task, regenerate the schedule in Section 3 to see
the updated plan.

## Best practices for building a schedule in this app
Mark medication and other must-not-miss tasks as "required" so they are
never dropped when the time budget is tight. Set a realistic daily time
budget that reflects how much time is actually available, not an ideal
day -- this keeps the generated plan trustworthy. Review conflict warnings
before starting the day rather than discovering overlaps in the moment.
